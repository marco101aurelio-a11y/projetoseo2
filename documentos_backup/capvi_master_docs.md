# Capvi SEO - Documentação Master V5.4 🧠📊

## 1. Visão Geral
**Capvi SEO** é uma plataforma de aceleração e auditoria de palavras-chave, focada em maximizar o retorno sobre investimento (ROI) através de inteligência artificial.

## 2. Changelog Recente
### [V5.4] — Atualização de Sistema Control
- **CRUD de Configurações**: Implementada funcionalidade real na aba de Configurações (Edição de Perfil, Voz da IA e Toggles de API).
- **Persistência Local**: Integração com `localStorage` para manter preferências do usuário.
- **Documentação Modular JAX**: Criação do guia de arquitetura e fluxo BPMN 2.0 para os motores JAX.
- **Login Premium**: Sincronização com o novo "Capvi Drop" e refatoração visual da tela de acesso.

## 3. Pilares de Design (Original Slate)
- **Cores**: Slate, Indigo, White, Emerald/Rose (Alertas).
- **Interface**: Baseada em `glass-panel` e `premium-input`.
- **Foco**: Clareza, legibilidade e performance de dados.

## 4. Arquitetura de Inteligência
- **Frontend**: React + Vite + Tailwind.
- **Motor JAX**: FastAPI + Python (Cálculos financeiros e DRE).
- **Voz da IA**: Integração Gemini para insights estratégicos.
